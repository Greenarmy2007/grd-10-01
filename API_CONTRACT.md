# API Contract: GRD-10 Nomination Submission

This document defines the backend API contract for `submit-nomination`. It enables future hosting transitions (e.g. migrating from Netlify Functions to Vercel Serverless Functions, AWS Lambda, Cloudflare Workers, or Express.js) without altering the frontend nomination client.

---

## 1. Endpoint Overview

- **Default Relative Path:** `/.netlify/functions/submit-nomination`
- **Frontend Override:** Can be customized globally by declaring `window.GRD_API_ENDPOINT = "https://your-api-domain.com/api/submit-nomination";` prior to loading `js/nomination.js`.
- **Supported HTTP Method:** `POST` only. All other methods must return `405 Method Not Allowed`.
- **Request Content-Type:** `application/json`
- **Response Content-Type:** `application/json`

---

## 2. Server-Side Environment Variables

The server must read three private environment variables:

| Variable | Description | Example |
| :--- | :--- | :--- |
| `RESEND_API_KEY` | Resend API secret key | `re_123456789...` |
| `NOMINATION_RECIPIENT_EMAIL` | Destination inbox for jury review | `jury@example.com` |
| `NOMINATION_FROM_EMAIL` | Verified sender configured in Resend | `GRD-10 <nominations@yourdomain.com>` |

> **Security Note:** Neither the Resend API key nor recipient configuration are ever sent to or processed by the frontend browser.

## 3. Request Schema (JSON)

### Request Payload Example

```json
{
  "referenceId": "GRD-2026-NOM-84920",
  "nomineeName": "Dr. Ramesh Chandra Patil",
  "category": "Medicine & Healthcare",
  "organisation": "Rural Primary Health Center, Sangli",
  "cityState": "Sangli, Maharashtra",
  "reason": "Dr. Ramesh Patil has spent over three decades providing free rural medical clinics to impoverished agrarian families in Sangli district without seeking commercial compensation or institutional fame. His tireless dedication to public health exemplifies the selfless principles of Shri Ghanshyam Dube.",
  "keyContribution": "Established 4 permanent community clinics, trained 150 grassroots health volunteers, and provided preventive care to more than 60,000 villagers across Western Maharashtra.",
  "nomineeContact": "+91 98220 12345 / dr.patil@ruralhealth.org",
  "nominatorName": "Anand Deshmukh",
  "nominatorContact": "anand.d@example.org | +91 91234 56789",
  "website_url": "",
  "submittedAt": "2026-10-14T12:00:00.000Z",
  "fileNames": [
    "citation_letter.pdf",
    "clinic_photographs.jpg"
  ]
}
```

### Field Definitions & Validation Rules

| Field | Type | Required | Max Length | Notes |
| :--- | :--- | :--- | :--- | :--- |
| `referenceId` | string | Optional | 50 chars | Client-generated tracking ID. Fallback generated by server if missing. |
| `nomineeName` | string | **Yes** | 150 chars | Full name of the candidate. |
| `category` | string | **Yes** | 100 chars | One of the approved categories. |
| `organisation` | string | **Yes** | 200 chars | Profession, NGO, clinic, school, or community role. |
| `cityState` | string | **Yes** | 150 chars | District / City and State in India. |
| `reason` | string | **Yes** | 10,000 chars | Why nominated. Minimum 30 words required. |
| `keyContribution` | string | **Yes** | 10,000 chars | Measurable impact, achievements, and public service. |
| `nomineeContact` | string | **Yes** | 200 chars | Private email or telephone for committee fact-checking. |
| `nominatorName` | string | **Yes** | 150 chars | Full name of the submitting party. |
| `nominatorContact` | string | **Yes** | 200 chars | Email & mobile of the submitting party. |
| `website_url` | string | No | N/A | **Anti-spam honeypot**. Must be empty. If populated, request is rejected as bot spam. |
| `submittedAt` | string | No | N/A | ISO timestamp. |
| `fileNames` | string[] | No | 10 items | Names of uploaded documents (max 100 chars per filename). |

## 4. Response Schemas

### 4.1 Success (200 OK)

Returned **only** when input validation passes and Resend confirms dispatch of the notification email.

```json
{
  "success": true,
  "referenceId": "GRD-2026-NOM-84920",
  "message": "Nomination dossier successfully received, validated, and dispatched to the Selection Committee.",
  "recipient": "jury@example.com"
}
```

### 4.2 Validation Error (422 Unprocessable Entity)

Returned when required fields are missing or fail schema validation.

```json
{
  "success": false,
  "error": "Validation Error",
  "message": "The submitted nomination failed validation.",
  "details": [
    "Nominee Full Name is required.",
    "Nomination reason must be at least 30 words."
  ]
}
```

### 4.3 Spam Detected (400 Bad Request)

Returned when the honeypot field is filled.

```json
{
  "success": false,
  "error": "Spam Detected",
  "message": "Automated submission rejected."
}
```

### 4.4 Method Not Allowed (405 Method Not Allowed)

Returned on GET, PUT, DELETE, PATCH requests.

```json
{
  "success": false,
  "error": "Method Not Allowed",
  "message": "Only HTTP POST requests are supported."
}
```

### 4.5 Payload Too Large (413 Payload Too Large)

Returned when the request body exceeds 100 KB.

```json
{
  "success": false,
  "error": "Payload Too Large",
  "message": "The submitted nomination dossier exceeds the maximum allowed size."
}
```

### 4.6 Configuration Missing (503 Service Unavailable)

Returned when server environment variables (`RESEND_API_KEY`, etc.) are not yet configured in Netlify.

```json
{
  "success": false,
  "error": "Service Unavailable",
  "message": "The nomination dispatch system is temporarily unconfigured. Please contact the GRD-10 Secretariat directly."
}
```

### 4.7 Email Transmission Provider Failure (502 Bad Gateway)

Returned if the Resend API rejects the request or fails authentication.

```json
{
  "success": false,
  "error": "Email Dispatch Error",
  "message": "Unable to deliver nomination notification through email service provider. Please retry shortly or contact the secretariat directly.",
  "referenceId": "GRD-2026-NOM-84920"
}
```

## 5. Portability Guide: Migrating to Vercel or Other Hosts

To run this backend on **Vercel** in the future:
1. Copy `netlify/functions/submit-nomination.js` to `/api/submit-nomination.js`.
2. Adapt the export signature to Vercel standard:
   ```javascript
   export default async function handler(req, res) {
     if (req.method !== 'POST') return res.status(405).json({ ... });
     // ...
   }
   ```
3. Set the environment variables in Vercel Project Settings.
4. Set `window.GRD_API_ENDPOINT = '/api/submit-nomination';` or leave it default if mapped via `vercel.json` rewrites.
